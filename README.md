# ZAD Restaurant Management System

نظام إدارة مطاعم عربي (RTL) بواجهة ويب متجاوبة، مبني باستخدام HTML/CSS/JavaScript بدون اعتماد على خادم.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` باستخدام متصفح حديث (Chrome أو Edge أو Firefox).
3. اختر الفرع من القائمة الجانبية وابدأ تجربة الأقسام.

لا يحتاج إلى تثبيت حزم أو إعداد قاعدة بيانات.

## الوظائف الموجودة
- لوحة تحكم ومؤشرات أداء للفروع.
- نقطة بيع وإضافة أصناف للسلة وتأكيد الطلب وطباعة فاتورة.
- إدارة حالة الطاولات.
- شاشة متابعة المطبخ وتحديث حالة الطلب.
- إدارة الأصناف والمخزون والموردين والموظفين والفروع والمصروفات (إضافة/تعديل/حذف/بحث).
- تقارير مختصرة.
- حفظ تلقائي في Local Storage.
- تصدير واستعادة نسخة احتياطية JSON.

## بيانات الدخول
لا توجد شاشة دخول في هذه النسخة؛ افتح التطبيق مباشرة. لا تستخدمها كنظام إنتاج فعلي قبل إضافة مصادقة وصلاحيات خادمية.

## ملاحظات مهمة قبل التشغيل التجاري
هذه نسخة MVP تشغيلية للواجهة والعمليات الأساسية وليست نظام ERP إنتاجيًا مكتملًا. البيانات محفوظة داخل المتصفح وعلى الجهاز نفسه، ولا تتم مزامنتها بين الأجهزة أو الفروع. يلزم قبل التشغيل الحقيقي:
- Backend API وقاعدة بيانات مركزية (مثل PostgreSQL).
- تسجيل دخول آمن، أدوار وصلاحيات دقيقة وسجل تدقيق.
- مزامنة الفروع، إدارة الورديات وإقفال الخزينة.
- ربط المخزون بالوصفات (BOM) وخصم الخامات تلقائيًا عند البيع.
- إدارة مشتريات فعلية وفواتير موردين ومدفوعات.
- اختبارات، نسخ احتياطي مجدول، HTTPS ونشر على استضافة.
- مراجعة الضرائب والفاتورة الإلكترونية ومتطلبات القوانين المحلية والتكاملات المناسبة في مصر.

## التقنية
Vanilla JavaScript + CSS + HTML. لا توجد مكتبات خارجية لازمة؛ خط Cairo يتم تحميله من Google Fonts عند توفر الإنترنت، مع خط بديل محلي.
